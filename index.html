Featured Projects

AgentGem

The stepping stone to a Shopify for AI agents. AgentGem reads your coding-agent config — skills, MCP servers, CLAUDE.md — redacts secrets the moment they're read, and packages it into a portable, composable Gem: a manifest + lock archive you publish to a GitHub-backed registry, merge with other Gems, and deploy to multiple targets (Eve, Flue, OpenAI Sandbox, AgentCore, Claude Agents). Secrets never leave your device — only a config shape with <redacted> in place of every sensitive value crosses any boundary. The thesis: you can't profit from a markdown file — turn agents into callable, monetizable services. Built on AgentBack.

AgentBack

A modernization and reimagining of LoopBack 4 for the AI agent era — an AI-native API/MCP framework built with agents, for agents. Your API now has two audiences: human developers and AI agents. Instead of describing each operation four or five times (Zod schema, OpenAPI block, MCP tool, client type), AgentBack describes it once: one Zod contract becomes the validator, the inferred type, the OpenAPI 3.1 docs, the MCP tool, the typed client, and the generated SKILL.md. Built on a modern ESM, DI core descended from LoopBack 4's container that runs on any host — Node, Fastify, Hono, Bun, Deno, or Workers — from a single fetch handler.
